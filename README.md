# IFN-low SLE single-sample networks (Paper 2)

Do per-patient LIONESS partial-correlation networks separate interferon-low SLE from healthy controls better than WGCNA, linear expression, and distance-from-health baselines?

Pascal Antwi, with Dr Tyler Grimes. Planning stage. Follows on from the osteosarcoma LIONESS pilot in [`lioness-network-analysis`](https://github.com/pascalantwi/lioness-network-analysis).

- `IFN_LOW_NETWORK_PLAN.md`: the current study plan. Target journal: *Briefings in Bioinformatics*.
- `context/`: the sister leakage-paper plan (Paper 1), which this plan references, and the README of the osteosarcoma pilot.
- `reviews/`: critiques and revision notes on the plan.
